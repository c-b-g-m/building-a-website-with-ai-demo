# Bayou Brew Coffee

Website for Bayou Brew Coffee, a small coffee shop in the Houston Heights.

## Stack

- HTML, CSS — no framework
- Single shared stylesheet at `styles.css`
- Hosted on Vercel (auto-deploys from `main`)
- `brand-kit.md` is the source of truth for colors, typography, voice, and layout primitives

## Pages

- `index.html` — home + menu
- `about.html` — about the shop
- `contact.html` — visit info + contact form

## Conventions

See `CLAUDE.md` for project conventions and pre-commit checklist.
See `brand-kit.md` for the brand contract.

## Notes

This is a small static site project. New pages should follow the patterns in the existing pages and reference `brand-kit.md` before introducing any new visual or copy primitives.
